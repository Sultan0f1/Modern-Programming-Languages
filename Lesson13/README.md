# Lesson13 - Bomba oyunu

A Windows Forms game where each new colored panel increases the score. If a panel touches the bomb, the game-over message appears and a fresh round starts.

- **Panel yarat**: add a colored panel.
- **Bombanı köçür**: move the bomb to a new random position.
- **Çıxış**: close the game.

Open Lesson13.sln in Visual Studio, or run dotnet run --project Lesson13.csproj on Windows with the .NET 8 SDK installed.
