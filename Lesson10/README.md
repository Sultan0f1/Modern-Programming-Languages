# Lesson 10 — Təyyarə simulyatoru

**Müəllif: Nicat**

Windows Forms layihəsi: təyyarə paneli, elan düymələri, işıq idarəsi və sadə uçuş animasiyası.

Visual Studio-da `teyyare-line.csproj` faylını açın. Layihə .NET Framework 4.6.1 istifadə edir. Səslər üçün WAV fayllarını `Resources/Audio` qovluğuna yerləşdirin: `inishazirliklari.wav`, `turbulans.wav`, `kemerler.wav`, `tesekkurler.wav`, `beep.wav`, `isikacmakapamasesi.wav`. İlkin repoda səs faylları verilməyib; olmadıqda tətbiq işləməyə davam edir.

Uyğunlaşdırma [LedmaxPC/teyyare-line](https://github.com/LedmaxPC/teyyare-line) nümunəsi əsasında hazırlanıb.
